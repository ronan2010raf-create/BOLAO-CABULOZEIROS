# BOLÃO CABULOZEIROS

Aplicativo web para acompanhar a classificação do bolão, lançar pontos por rodada, gerenciar participantes e exportar a tabela como imagem para compartilhar no WhatsApp.

## Publicação no GitHub Pages

1. Abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/ (root)** e clique em **Save**.
4. Aguarde o GitHub publicar o site. O endereço será `https://ronan2010raf-create.github.io/BOLAO-CABULOZEIROS/`.

## Observação sobre dados

Esta versão inicial armazena os dados no armazenamento local do navegador. Para usar em outro aparelho, exporte um backup JSON no menu Backup e importe-o no outro aparelho. Sincronização em nuvem multiaparelho ainda não foi configurada.
